# Entropy-Controlled Quantum Simulation

How does the ability to remove entropy during a noisy evolution change the number of oracle calls needed to simulate it?

This project classifies the query cost of a prescribed controlled evolution generated by one unknown Hermitian reflection. The target retains only two qubits, but known controls can repeatedly remove entropy and preserve sensitivity to the unknown noise axis. Their total entropy-decrease capacity determines a sharp crossover between square-root and linear query cost.

## Principal result

Let the unknown reflection satisfy $`U=U^\dagger`$ and $`U^2=I`$, and let its rate-one noise generator be $`\mathcal L_U(\rho)=U\rho U-\rho`$. Between noisy intervals, apply known CPTP controls $`C_0,\ldots,C_r`$, independent of the unknown oracle. The total noisy exposure is $`T`$. Charge every control, including any initial or terminal reset, according to

```math
\kappa(C)=\max_\rho\{S(\rho)-S(C\rho)\},
\qquad
\sum_{k=0}^{r}\kappa(C_k)\leq E.
```

Entropy uses natural logarithms. Unital controls have zero capacity; replacing a qubit by a state $`\tau`$ has capacity $`\log2-S(\tau)`$. This quantity is the negative of established minimum entropy gain; [the capacity account](science/entropy_capacity.md) gives the properties and attribution.

Given ordinary controlled-$`U`$ access, the worst-case bounded number of queries required to simulate the complete target channel to diamond error $`0.01`$ is

```math
\boxed{
Q_4(T,E,0.01)
=\Theta\!\left(\min\{T,\sqrt{T(1+E)}\}\right),
\qquad T\geq1,\quad E\geq0.
}
```

The guarantee covers every input, including one entangled with an untouched reference. The constants are independent of time, capacity, and the number of control boundaries. The [model](science/model.md) fixes the promise and oracle contract; [query complexity](science/query_complexity.md) proves the matching upper and lower bounds.

| Target control capacity | Query order | Exact two-qubit witness |
|---|---:|---|
| Bounded $`E`$, including zero | $`\sqrt T`$ | Maximally mixed syndrome replacement |
| $`1\ll E\ll T`$ | $`\sqrt{TE}`$ | Partially polarized syndrome replacement |
| $`E=\Omega(T)`$ | $`T`$ | Pure syndrome replacement |

Zero capacity permits repeated unital interventions. A single reflection without interventions has an exact sampler requiring at most one query; [the interpretation](science/interpretation.md#one-reflection-without-interventions) explains why these are different target classes.

## The channel bound behind the algorithm

For a retained system of dimension $`D`$, consider matched Hermitian Lindblad jumps $`A_j(s),B_j(s)`$, common weights $`p_j(s)`$, a common Hamiltonian, and the same CPTP controls. Define

```math
V^2=\int_0^T\sum_jp_j(s)
\|A_j(s)-B_j(s)\|_{\mathrm{op}}^2\,ds.
```

The complete channels obey

```math
\boxed{
\|\Phi_A-\Phi_B\|_\diamond
\leq V\left[1+\sqrt{4\log D+2E}\right].
}
```

The proof combines the entropy that can accumulate during the noisy intervals with a backward-observable variance identity that survives arbitrary common CPTP controls. It includes singular inputs and pure resets, arbitrary untouched references, and bounded piecewise continuous time dependence. It requires no spectral gap or mixing assumption.

A [two-qubit mixed-reset construction](science/mixed_resets.md) attains the time-and-capacity dependence at fixed noise rate through an exact finite-distance signal. [Local-noise examples](science/memory_and_local_noise.md) establish the dimension dependence and clarify the separate role of retained qubits and pure-reset count.

## Reproduce the finite checks

From the repository root, using Python 3.12:

```bash
python3 -m pip install -r requirements.txt
python3 verification/checks.py
```

The deterministic suite compares controlled Duhamel, entropy, and variance identities; direct two-qubit circuits against their exact coherence formula; finite capacity witnesses; and local GHZ outputs against the binomial signal and entropy formulas. It prints a summary and writes no file by default. [Verification](verification/README.md) specifies the parameter grids, tolerances, reference environment, and optional JSON output.

The written proofs establish the universal statements. The finite checks supply reproducible evidence for the identities and implementations they exercise; they do not numerically certify the diamond-norm or asymptotic theorems.

## Scope and attribution

This is a fixed-error query theorem for a known sequence of target controls. The simulator may use auxiliary learning probes, memory, measurements, and classical processing; all unknown-oracle calls count. The capacity budget applies to the target controls. Runtime, known-gate count, and arbitrary-dimensional optimal query complexity are separate questions.

The channel theorem compares supplied matched Hermitian jumps and includes every retained quantum or classical record in $`D`$. Its finite trace-distance statement does not assert a quantum-Fisher-information bound or a thermodynamic work cost.

Entropy gain, unitary learning, and the informative-noise reset mechanisms have explicit predecessors. The [source comparison](references/RELATED_WORK.md) identifies those ingredients and distinguishes them from the combined capacity-dependent channel bound and controlled-query classification.
